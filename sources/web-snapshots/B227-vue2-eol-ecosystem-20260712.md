# Snapshot — Vue 2 EOL + ecosystem status (for B227 modernization block)
# Query: "Vue 2 end of life status ViewUI iView Vuex Pinia"  ·  accessed 2026-07-12
# Primary source: https://blog.vuejs.org/posts/vue-2-eol  ·  https://v2.vuejs.org/eol/

- **Vue 2 reached End of Life on 2023-12-31.** Vue 2.7 (final release) stopped receiving security patches
  on that date. Source: The Vue Point (blog.vuejs.org/posts/vue-2-eol), v2.vuejs.org/eol.
- Post-EOL extended support only via HeroDevs "Never-Ending Support" (NES) — paid, for compliance.
- **Pinia** is the recommended state management for Vue 3, successor to Vuex.
- Modern Vue apps: Composition API, Pinia, composables, TypeScript, Vite.
