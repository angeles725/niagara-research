Horarios maestros

Cinco programas para todo el edificio. Toca la semana de un horario para editar su programa (tipo Niagara). El HOA manda sobre todos los circuitos que lo siguen: Auto = sigue el programa · Override = enciende todos · Off = apaga todos.

Tableros por nivel

Toca un tablero para ver sus circuitos y elegir a cuál horario hace caso cada uno.

La letra (A–E) elige el horario de cada circuito. El estado sigue el HOA de ese horario.
Arrastra sobre un día para crear un periodo encendido. Arrastra el bloque para moverlo, el borde inferior para ajustar la hora, y la ✕ para borrarlo. Los cambios se reflejan al instante.
