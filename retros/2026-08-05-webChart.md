# §18 Self-retrospective — focus `webChart` (niagara-research)

**Date**: 2026-08-05 · **Focus**: `webChart` · **Blocks**: B368–B377 (9 evidence + 1 synthesis) ·
**Gaps**: 9/9 closed (+1 child W7-G1 requires-execution) ·
**Run mode**: orchestrated-supervised; bootstrapped AND closed in one session; W1-W2 sequential sweeps, **W3-W9 as
7 parallel fresh-context sweeps in 2 waves** + inline driver verify/write per block.

> This retro **PROPOSES** kit deltas. It does not edit `$KIT`. Each proposal carries the evidence that motivated
> it and a check of whether the current kit already covers it.

## Run summary

Focus born from the `reports` charting thread ([B362]/[B366]/[B367]): after proving the alarm band is custom on
every charting path, the user chose to document `webChart` in full breadth. Bootstrapped (71 artifacts measured,
9 audit-first gaps) and closed 9/9 the same session. W1 (line engine) and W2 (model) ran as single sequential
sweeps with 5 and 7 load-bearing citations driver-verified. W3-W9 ran as **7 parallel general-purpose sweeps** —
one wave of 4 (client-side: types/commands/FEs/export), one wave of 3 (server/extension/file) — each returning a
map with a "LOAD-BEARING CITATIONS" tail that the driver spot-verified before writing the block. Two findings were
decision-relevant beyond documentation: the default-`average` sampling that erases limit crossings (B369), and the
`/schedule`+`/boxTable` permission fall-through (B374 → W7-G1). One apparent cross-block contradiction (render
closed B368 vs factory open B375) was resolved as a layer distinction, not a §14 correction.

## What went well

- **Remittance-scoped sweep prompts.** Each sweep prompt named exactly what prior blocks ([B199], [B366-B369])
  already covered and told the agent to treat it as remittance. This kept 7 parallel agents from re-deriving the
  spine and let each go straight to the un-mapped depth. Zero duplicated coverage across the 7.
- **Load-bearing-tail contract.** Every sweep prompt demanded a closing "LOAD-BEARING CITATIONS" list (the N most
  important `file:line`). The driver verified only those against disk before writing — fast, and it caught the
  one framework-semantic nuance (B369's `chartLimitMode` lives in `ValueScale`, not the axis layer).
- **Security finding handled with the right hedge.** The W7 sweep flagged the `sendError`-without-`return` as a
  "potential defect, verify against your threat model." The driver verified the code omission ([CERT]) but routed
  *exploitability* — which depends on servlet-container commit semantics not in the corpus — to a named
  requires-execution child gap (W7-G1) instead of asserting a vuln.
- **Parallel fan-out held quality.** 7 concurrent sweeps did not degrade verification: each block still got its
  load-bearing citations re-resolved to disk, self-verify table, and marker tally.
